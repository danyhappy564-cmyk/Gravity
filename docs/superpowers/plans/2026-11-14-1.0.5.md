# Gravity 1.0.5 구현 계획

> **실행 방식:** superpowers:executing-plans (사용자 규칙: 서브에이전트 금지 — Claude가 직접 구현). 단계는 체크박스(`- [ ]`)로 추적한다.

**목표:** 웹 언어 저장, 자동 프리셋 이름 번역, 보스 맵별 확률, 의상 탭(모드 단위), 기본 레이드 프리셋 값 점검, PMC 방탄복·헤드셋·판 하한 상향을 1.0.5로 묶어 배포한다.

**구조:** 웹은 한 파일 SPA(`src/Gravity.Server/wwwroot/index.html`), 서버는 SPT 4.1 C# 모드(`src/Gravity.Server`). 웹 설정 경로 → `ConfigModel.FromState`가 읽음 → 스폰(`RaidSpawnApplier`)·장비(`GearApply`)가 적용. 저장 형식(presets.json)은 바꾸지 않는다.

**기술:** .NET(xUnit `tests/Gravity.Tests`), Node 내장 test(`tests/web/ux.test.cjs`, vm 샌드박스).

**설계:** `docs/superpowers/specs/2026-11-14-1.0.5-design.md` (25aeefb)

## 검토 초점 (테스트로 고정할 것)

1. **브라우저 저장소가 막힘/`navigator` 없음** → 언어는 `en` 또는 저장값 없이도 화면이 뜬다(테스트 샌드박스에 `navigator`가 없다 — `typeof navigator` 가드). → Task 1
2. **옛 config에 기본값 그대로 저장된 장비 표(`tierData`)** → 사용자가 손대지 않은 옛 기본 숫자(방탄복 40 계열·헤드셋 15 계열·앞뒤판 90)만 새 기본으로 바꾸고, 사용자가 고친 숫자는 그대로. → Task 5
3. **의상 설정을 한 번도 안 건드린 기존 사용자** → 봇 외형을 전혀 바꾸지 않는다(다른 모드가 입힌 옷도 그대로). 의상 탭을 한 번 저장한 뒤부터 허용/비허용 규칙 적용. → Task 4
4. **맵별 확률 0** → "비움(기본 사용)"과 다르다: 0이면 그 맵에서 안 나온다. 칸 비우기 = 키 삭제. → Task 3
5. **영어로 만든 프리셋을 한국어 화면에서 봄** → `Custom preset 3`이 `커스텀 프리셋 3`으로 보이고, 다음 번호는 두 언어를 합쳐 센다(4). → Task 2
