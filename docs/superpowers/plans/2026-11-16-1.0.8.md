## 정한 기본값 (사용자가 바꾸라고 하면 바꿈)
1. 스캐브 **웨이브 몰림 = 보충 빈도**(앞이면 초반에 자주, 뒤면 후반에 자주), **인원 몰림 = 살아 있는 스캐브 상한**(앞이면 초반에 많이). 3칸 강도와 곱하고 합친 배수는 0.2~3으로 자름. 맵 동시 상한은 안 넘음.
2. 스캐브 '웨이브 목록'·'시작만' 방식에는 몰림 적용 안 함(목록은 사용자가 직접 정함) — 웹에서 칸을 흐리게+이유 표시.
3. 늦은 대원: 나오는 순간 그 지점이 사람에게서 PMC 거리 안이거나 분대장이 이미 죽었으면 **그 대원은 버린다**(상한 예약도 푼다). 분대장 근처로 옮기는 방식은 안 씀(또 겹칠 위험). 새 설정은 만들지 않는다.
4. 생성 중 분대 지점은 분대장 Active까지(최대 120초) 다른 분대 후보에서 뺀다.
5. 맵 전체 배치(Task 6b)는 새 설정 `spawn.wavePoints`(기본 `pmc` = 지금과 같음). 재현 판에서 웨이브 분대가 플레이어 시작 지점에 몰리는 것이 확인되면, **기본값에서도** 웨이브 분대의 "플레이어 시작 지점 먼저" 단계를 뺄지 사용자에게 묻는다(기본 동작 변경은 사용자 결정).
6. 총량 상한(Task 6c)은 기본 꺼짐. 닿으면 **Gravity가 내는 스폰만** 멈춘다. 보스·레버 트리거·이벤트·다른 모드 봇은 세기만 하고 막지 않는다(반쪽 분대·트리거 깨짐·타 모드 충돌 방지). 사람(플레이어·Fika 클라)은 안 셈.
