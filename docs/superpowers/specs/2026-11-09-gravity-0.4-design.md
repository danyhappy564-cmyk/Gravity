# Gravity 0.4 설계: 보스 다른 맵·저격 스캐브·스캐브 밀도

> **상태: 초안, 사용자 미승인.** 0.3 설계(`2026-11-09-gravity-0.3-bosses-design.md`)의 제약을 그대로 따릅니다. **[검토 필요]** = 1.0 때 한 번에 검토.

## 1. 범위

| 번호 | 기능 | 어디서 |
|---|---|---|
| H1 | 보스를 원래 없던 맵에 놓기: 웹 `bosses.<id>.maps.<맵>=true`인데 그 맵 DB에 항목이 없으면, DB 다른 맵에서 확률이 가장 높은 항목을 본보기로 복제(발동 조건 지움, `SptId=gravity`). 구역은 웹에서 고른 실제 이름, 없으면 그 맵의 보스·PMC 구역 전부(저격 구역 제외). 즈랴치는 등대 섬 전용이라 제외 | 서버 |
| H2 | 저격 스캐브(`specials.snipers`): 끄면 marksman 웨이브 삭제, 맵 확률은 웨이브마다 남길 확률, 인원 칸은 SlotsMin/Max | 서버 |
| H3 | 스캐브 밀도: 0.3 보고의 사망 수로 공장 판을 다시 보고 `scav.refill` 기본값을 정함 **[검토 필요]** | 서버 기본값 |
| H4 | 웹: `noVanilla`는 Gravity가 바닐라 항목을 직접 고치므로 효과 없음(안내), 0.5 띠 | 웹 |

**0.4에서 하지 않는 것(0.5 이후)**: 이벤트(할로윈 등 SPT 시즌 이벤트 제어), 팩션 모드(RUAF·UNTAR·BlackDiv 관리), 감염자 무리, 장비(0.5), ORBIT 연동·프리셋(0.6), 핫스팟 부스트·상한 무시, 스캐브 레이드 때 남는 봇, 늦게 오는 레이더, 근처 보충 기본 칸.

## 2. 판정

- 판정 25: 웹 저격 확률 기본값(세관 65% 등)을 그대로 적용한다 → 저장된 기본값이면 저격 웨이브가 일부 빠진다. 웹이 보여 주는 뜻과 같음.
- 판정 26: 새 맵 보스의 확률은 웹 `chance`(공통 확률이 켜져 있으면 그것), 추가 스폰도 같은 규칙.
