# Gravity 0.4 설계: 팩션 모드 관리·다른 모드 PMC 구분

> **상태: 초안, 사용자 미승인.** [검토 필요] = 1.0 때 한 번에 검토. 원래 로드맵 기준 0.4입니다(판 번호는 0.3 나머지 설계 문서 머리말 참고).

## 1. 범위

| 번호 | 기능 | 어디서 | 적용 시점 |
|---|---|---|---|
| F1 | RUAF 관리: 순찰·검문소·사냥조(켜기·확률·개수·인원·등장 시각), 맵 켜고 끄기, 동시 상한 같이 쓰기 | 서버 레이드 복제본 | 판마다 |
| F2 | BlackDiv 관리: 맵마다 사냥조(확률·시점·인원), 연구소 웨지·게이트, 블랙아웃 연동 | 서버 레이드 복제본 | 판마다 |
| F3 | 다른 모드가 넣은 PMC 항목 구분(그대로 둠/Gravity 계획으로 바꿈) | 서버 `RaidSpawnApplier` | 판마다 |
| F4 | 웹: 설치 여부·모드 기본 맵·블랙아웃 확률을 실제 값으로, 다른 모드 PMC 선택 칸, 띠 문구 | 웹 | |

UNTAR는 이 게임에 설치되어 있지 않아 봇 이름·항목 모양을 확인할 수 없습니다. 판정 36: 0.4에서는 다루지 않고 웹에 "설치되지 않음"으로 표시합니다. **[검토 필요]** 비용: UNTAR 사용자는 모드 자체 설정으로만 동작.

## 2. 두 모드가 스폰을 넣는 방식(읽기 전용 분석)

- 두 모드 다 서버 시작 때와 레이드가 끝날 때마다(`/client/match/local/end`) SPT 맵 DB의 `BossLocationSpawn`을 지우고 새로 굴려 넣습니다. 레이드가 시작되면 SPT가 DB를 복제하고, Gravity는 그 복제본(`GenerateLocationAndLoot` 뒤)을 고칩니다. 그래서 Gravity가 고친 값은 그 판에만 들어가고 모드의 DB 값은 그대로입니다.
- RUAF: 순찰·검문소는 우두머리 `ruafRiflemanSenior`, 호위는 `Supports`(소총수·전문병). 검문소는 시작 때(`Time=-1`) 모드 설정에 좌표가 있는 구역에만 나옵니다(RUAF 클라가 `/ruaf/checkpoints`로 좌표를 받아 엄폐 지점을 찾음). 사냥조는 `TriggerId="hunt"`로 RUAF·레넌트·전 USEC(`exUsec`) 세 종류입니다.
- BlackDiv: 맵마다 사냥조 하나(`blackDivAssault`, `TriggerId="hunt"`, 구역 빈 값). 연구소는 웨지 무리(`bossWedge` + `blackDivIb`, 설정 `labsStartChance`가 웨지 확률)와 게이트 두 곳(`autoId_00632_EXFIL`=Gate1, `autoId_00014_EXFIL`=Gate2). 게이트를 차지하면 그 트리거를 쓰는 바닐라 항목(레이더)을 전부 지웁니다.
- Blackout: 레이드가 끝날 때 다음 연구소 판의 정전 여부를 서버에서 정해 둡니다(`CurrentRaidBlackout`).

## 3. F1 RUAF (관리 켬일 때)

- 판정 33: 관리 = 그 판 복제본에서 모드가 넣은 항목을 지우고 웹 값으로 Gravity가 새로 만듭니다. 관리 끔이면 손대지 않습니다.
- 판정 34: Gravity가 만드는 것은 RUAF 봇(`ruaf*`) 항목입니다. 레넌트·전 USEC 사냥조는 모드가 넣은 그대로 두고, 그 맵을 끈 경우에만 같이 지웁니다. **[검토 필요]** 비용: 웹 "사냥조" 칸이 레넌트·전 USEC 사냥조에는 안 먹음.
- 맵: 웹에서 그 맵을 켰는지(`factions.ruaf.maps.<맵>`). 값이 없으면 RUAF 설정 파일에 있는 맵이 기본입니다. 끈 맵은 RUAF 항목을 모두 지웁니다.
- 순찰: `count`개, 각각 확률 `chance`, 인원 `min~max`, 등장 시각 `tMin~tMax`분(레이드 끝 1분 전까지로 자름), 구역은 RUAF 설정의 순찰 구역을 겹치지 않게 돌려 씁니다. 설정에 없는 맵이면 이번 판 복제본의 RUAF 구역, 그것도 없으면 맵의 PMC 구역입니다.
- 검문소: `count`개, 시작 때, 구역은 RUAF 설정의 검문소 구역(좌표가 있어야 함)만 씁니다. 좌표 있는 구역이 없는 맵에는 만들지 않습니다. 판정 35: "지키는 반경"은 RUAF 클라가 자기 설정 값을 읽으므로 적용하지 않습니다(웹에 표시). **[검토 필요]**
- 사냥조: 확률 `chance`, 인원 `min~max`, 등장 시각은 레이드의 10~90% 사이 무작위, 구역은 RUAF 설정의 RUAF 사냥 구역(없으면 순찰 구역 전체)입니다.
- 무리 구성: 우두머리 1명(선임 소총수) + 인원 3명마다 전문병 1명(사수·기관총수·자동소총수 중 무작위) + 나머지 소총수. 항목 모양은 모드와 같게(`Supports`, 난이도 normal) 둡니다.
- 판정 41: "PMC 동시 상한을 같이 씀"은 `IgnoreMaxBots = !shareCap`입니다. 끄면(기본) 맵 봇 상한이 차도 나오고, 클라 스캐브·근처 보충이 상한을 셀 때 관리 중인 팩션 봇을 뺍니다(서버가 역할 이름·번호 목록 `CapExclude`를 보냄). 세관 첫 판에서 RUAF 15명이 상한을 채워 스캐브가 0명 나온 것을 보고 더했습니다. 관리하지 않는 팩션은 바닐라처럼 다 셉니다.

## 4. F2 BlackDiv (관리 켬일 때)

- 사냥조: 웹에서 켠 맵(값이 없으면 BlackDiv 설정의 `huntMaps`)마다 모드 사냥조를 지우고, 확률 `bd.chance`·인원 `huntMin~huntMax`·등장 시각 레이드 `tMin~tMax`% 사이 무작위로 하나 넣습니다. 끈 맵은 사냥조를 지웁니다.
- 연구소 웨지: `wedge`가 켜져 있으면 웨지 항목 확률을 `wedgeChance`로, 꺼져 있으면 지웁니다. 판정 37: 모드의 `labsStartChance`가 곧 웨지 확률이라 웹의 "연구소 시작부터 있을 확률" 칸은 웨지 확률과 합칩니다(칸 삭제). **[검토 필요]**
- 연구소 게이트: 게이트마다 `labsGate`% 로 굴립니다. 되면 그 트리거의 바닐라 항목 중 게이트 구역 항목을 BlackDiv 무리로 바꾸고, 안 되면 바닐라 항목을 그대로 둡니다. 판정 38: 모드가 이미 게이트를 차지해 바닐라 항목을 지운 판이면 SPT 원본 맵 데이터(`SPT_Data/database/locations/laboratory/base.json`)에서 다시 넣습니다. 모드와 달리 게이트를 차지해도 같은 트리거의 층별 레이더는 지우지 않습니다. **[검토 필요]**
- 블랙아웃 연동(`lab.blackoutLink`): 판정 39: Blackout 모드가 정해 둔 이번 판 정전 여부를 읽기만 합니다(리플렉션, 못 읽으면 "상관없이"). `only`: 정전 판이 아니면 웨지·게이트 BlackDiv를 넣지 않습니다. `boost`: 정전 판이면 웨지·게이트 확률에 `blackoutMult`를 곱합니다(100% 상한).

## 5. F3 다른 모드 PMC 구분

- SPT는 레이드 복제본을 만들 때 PMC 항목(`pmcUSEC`·`pmcBEAR`)을 `pmc.json`의 맞춤 웨이브로 갈아 끼웁니다. 다른 모드는 이 목록에 PMC를 더할 수 있습니다.
- 판정 40: 서버 시작 때 SPT 원본 파일(`SPT_Data/configs/pmc.json`의 `customPmcWaves`, 맵 `base.json`의 PMC 항목)에서 항목 지문(역할·구역·확률·호위 수·트리거)을 모읍니다. 시각은 스캐브 레이드 때 SPT가 당기므로 지문에 넣지 않습니다. 복제본의 PMC 항목 중 지문이 남아 있으면 SPT 것, 없으면 다른 모드 것입니다.
- `compat.otherPmc`: `keep`(기본) = 다른 모드 PMC 항목은 남기고 Gravity 계획을 더합니다. `remove` = 0.3까지처럼 다 지우고 Gravity 계획만 넣습니다. 원본 파일을 못 읽은 맵은 전부 SPT 것으로 봅니다(0.3과 같음). **[검토 필요]** 비용: 다른 모드가 SPT PMC 웨이브 값을 직접 고친 경우 그 항목이 "다른 모드 것"으로 남아 PMC가 많아질 수 있음(진단 페이지·로그에 개수 표시).

## 6. 미룸

- 판정 42: 근처 보충 "직접 고르기"의 팩션 종류(RUAF·UNTAR·블랙 디비전)는 계속 스캐브로 나옵니다. 클라가 모드가 등록한 봇 종류 번호로 스폰해야 하는데 인게임 확인이 필요해 1.0 때 봅니다.
- ORBIT `TakeOver*` 연동은 0.6.

## 7. 시험

- 단위: RUAF 관리 끔/켬, 맵 끔, 순찰 개수·인원·시각 범위, 검문소 구역 없음, 사냥 구역 대체, 레넌트 유지; BlackDiv 사냥조 맵·시각 범위, 웨지 끔, 게이트 복원·차지, 블랙아웃 only·boost; 다른 모드 PMC 지문 구분(keep·remove·시각 무시); 설정 파일 읽기(JSONC).
- 인게임: ABPS를 잠깐 빼고 RUAF 관리 켬(세관 순찰 확률 100·개수 3) → 로그와 봇 목록에 RUAF 순찰. BlackDiv 관리 켬(공장 사냥조 100, 시각 1~2%) → 블랙 디비전 등장.
