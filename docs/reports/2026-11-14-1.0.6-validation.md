## 남은 것 (로컬)

1. 클라 Release 빌드(`dotnet build Gravity.sln -c Release`, TarkovDir 필요) 경고·오류 확인, zip 만들기·해시.
2. 실제 판(계획 Task 12): 세관 레이더·로그 추가 100%, 세관 컬티스트 낮 판, 연구소 레버 100%·역할 로그(BlackDiv·Blackout 설치), 리저브 D2 레버, 긴 판 스캐브 "PMC 반대로"(로그 `스캐브 강도 ×k`, 진단 자세히), 선택: 미궁 타길라 부하·RUAF 순찰 곡선.
3. 추가분 실제 판: 연구소 레버 지연 30초(당긴 뒤 30초쯤 뒤에 나오는지)·역할 비율 50%(여러 판에 레이더·로그가 섞이는지), 상한 자동 맞춤을 켠 맵의 로그 "동시 상한" 값, 폰으로 웹 열어 타임라인 누르기.
4. 3차 실제 판: 리저브나 세관을 "웨이브 목록"으로 두고 긴 판 — 로그 `스캐브 웨이브 목록 n개`·2분마다 `스캐브 웨이브 i/n: 낸 · 상한 대기 · 상한으로 버림`이 버블과 맞는지, 웨이브 사이에 스캐브가 채워지지 않는지. 옛 클라(1.0.5)와 섞으면 시작 스캐브만 나오는지. 티어 분포를 준 봇(예: 스캐브 T2 30·T4 70)이 실제로 섞여 나오는지(봇 장비 기록). 주간 보스: 서버 로그 `이번 주 보스 …`, 끄고 저장 → 맵 선택 화면 해골이 사라지는지, 켜면 그 보스가 매 판 나오는지. 봇 체력·스킬: "모든 티어: 체력 440 · 스킬 레벨 1"을 누르고 저장 → 스캐브·보스를 맞혀 보거나 사후 확인으로 체력 440 근처인지(보스가 원래보다 빨리 죽는지), SAIN·다른 봇 모드와 같이 켰을 때 오류 없는지.
5. 확인할 미검증 항목: 로그를 등대 밖에 넣었을 때 USEC 플레이어와의 관계, 컬티스트 낮 출현, 레버 무리를 로그·블랙 디비전으로 바꿨을 때 그 구역에서의 움직임, 트리거 항목 `Time` 값의 뜻(그대로 둠).
