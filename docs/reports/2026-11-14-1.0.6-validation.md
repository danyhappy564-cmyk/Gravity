### 추가분 (사용자 피드백 2차, 2026-11-14)

- 웹: 미리보기 위 "맵 동시 상한" 칸에 상한 팁(시작 인원·스캐브 목표·PMC 예약·PMC 동시 무리·특수 봇 최대 인원·상한 지킴·그룹 제한) + 고치기/모두 맞추기, "상한 자동 맞춤"(maps.<id>.capAuto, 저장 직전 maps.<id>.cap에 씀 — 서버 변경 없음), 맵 탭 아래쪽 limits 카드는 미리보기 편집이 켜져 있으면 숨김.
- 서버: 트리거 규칙 `delay`(0~600초, 없으면 원래 값)·`rolePct`(0~100, 없으면 100 = 1.0.6 처음과 같음). 역할 섞기는 무리마다 판 시작 때 굴림(시드 고정).
- 웹: 추가 무리·RUAF 순찰 시각 프리셋, 스캐브 강도 맵별 안내(서버는 이미 맵 스캐브 칸에서 읽음 — 테스트로 고정), `#demo` 시연 모드, 폰 타임라인 가로 스크롤·누르는 영역·아래쪽 창, 원래 무리가 없는 맵의 레이더 창에서 원래 시각 칸 숨김.

## 남은 것 (로컬)

1. 클라 Release 빌드(`dotnet build Gravity.sln -c Release`, TarkovDir 필요) 경고·오류 확인, zip 만들기·해시.
2. 실제 판(계획 Task 12): 세관 레이더·로그 추가 100%, 세관 컬티스트 낮 판, 연구소 레버 100%·역할 로그(BlackDiv·Blackout 설치), 리저브 D2 레버, 긴 판 스캐브 "PMC 반대로"(로그 `스캐브 강도 ×k`, 진단 자세히), 선택: 미궁 타길라 부하·RUAF 순찰 곡선.
3. 추가분 실제 판: 연구소 레버 지연 30초(당긴 뒤 30초쯤 뒤에 나오는지)·역할 비율 50%(여러 판에 레이더·로그가 섞이는지), 상한 자동 맞춤을 켠 맵의 로그 "동시 상한" 값, 폰으로 웹 열어 타임라인 누르기.
4. 확인할 미검증 항목: 로그를 등대 밖에 넣었을 때 USEC 플레이어와의 관계, 컬티스트 낮 출현, 레버 무리를 로그·블랙 디비전으로 바꿨을 때 그 구역에서의 움직임, 트리거 항목 `Time` 값의 뜻(그대로 둠).
