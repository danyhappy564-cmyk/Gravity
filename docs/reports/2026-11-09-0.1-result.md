# Gravity 0.1 결과 보고 (2026-11-09)

> 갈래 `design/skeleton-spawn`, 최신 `91d1a12`(로컬 커밋만, 공개 푸시 안 함). 설계 문서 `docs/superpowers/specs/2026-11-09-gravity-skeleton-spawn-design.md`.

## 1. 결론

- **0.1(서버 전용 PMC 스폰)은 세관에서 계획대로 동작합니다.** 확인 판에서 계획한 PMC 18명이 10분 안에 모두 나왔고, 진영 비율(USEC 9·BEAR 4)도 계획과 같았습니다. 대기열 0, 봇 생성 오류 0이었습니다.
- **공장·미궁에서는 PMC가 한 명도 나오지 않습니다.** 서버만으로는 고칠 수 없는 클라이언트 쪽 한계입니다. 0.2 클라이언트 플러그인에서 해결합니다.
- **스캐브·맵 동시 상한은 0.1에서 바닐라 그대로입니다.** 서버 데이터만 바꿔서는 통제되지 않는다는 것을 Codex 검토와 코드로 확인했습니다. 0.2로 넘깁니다.
- **게임에는 Gravity를 남겨 두는 것을 권장합니다.** ABPS가 있으면 스폰 기능이 스스로 꺼지므로 지금 플레이에 영향이 없습니다(4절).
- **공개 푸시는 아직 하지 않는 것을 권장합니다.** Gravity 저장소가 공개(PUBLIC)라 갈래만 올려도 누구나 볼 수 있습니다(5절).

### 세관에서 찾아 고친 원인

1. **첫 판(문제)**: 계획은 PMC 8명 시작 + 웨이브인데 실제로는 늘 1~2명이었습니다. 대기열에 16개가 쌓여 있었습니다.
2. **대조 판**: Gravity 스폰을 끄면 바닐라 PMC는 정상이었습니다. → 원인은 Gravity가 넣은 항목 쪽입니다.
3. **원인**: Gravity가 PMC 항목마다 구역 12개를 쉼표로 이어 넣었습니다. 클라이언트는 이 목록에서 구역 **하나만** 골라 레이드 끝까지 그 구역만 다시 시도합니다. 그런데 그 12개 중 6개(웨이드·기숙사·주유소 등)에는 PMC 스폰 지점이 아예 없었습니다. 그 구역을 고른 분대는 영원히 기다렸습니다.
4. **확인 판**: 구역 칸만 `""`(클라가 PMC 구역 전부를 차례로 시도)로 바꾸자 18/18명이 나왔습니다.
5. **정식 수정**(`5117a4d`·`91d1a12`): 웹의 PMC 구역 목록도 실제 PMC 지점이 있는 구역만 보이게 바꿨습니다(세관 12개 → 6개).

> 세관 확인은 실험 플래그(구역 `""`) 판으로 했습니다. 최종 커밋 DLL(`a95e5a46…`)로 세관을 다시 돌려 보지는 않았습니다. 구역을 전부 켠 기본 설정에서는 같은 동작이지만, 다음 시험 때 한 판 확인이 필요합니다.

### 따로 알게 된 것

- **봇 생성 오류(ConvertResourceInfo NRE)는 Gravity 탓이 아니었습니다.** APBS의 모드 옷 허용 설정과, 시험 때 ABPS를 빼서 ABPS 클라의 봇 프로필 정리 기능이 없었던 것이 겹친 결과입니다(kb 2.17). **Gravity가 ABPS를 대신하려면 같은 역할을 0.2 클라 플러그인에 새로 만들어야 합니다.**
- 확인 판 `errors.log`의 `ScopeZoomHandler` 오류 2246회는 PiP-Disabler 쪽 별건입니다. 이 작업에서는 손대지 않았습니다.

## 5. 게임에 남길지, 공개 푸시

**게임 — 남겨 두는 것을 권장합니다.**
- 지금 게임에는 ABPS가 있으므로 Gravity는 레이드마다 "ABPS 감지로 잠김" 한 줄만 남기고 맵 데이터를 바꾸지 않습니다(`GravityRuntime.TryApplyToRaid` 첫 줄에서 바로 빠짐).
- 남겨 두면 웹 화면에서 설정을 미리 맞춰 둘 수 있고, 다음 시험 때 다시 설치할 필요가 없습니다.
- 확인할 것 하나: ABPS를 되돌린 뒤로 서버를 아직 켜지 않았습니다. 다음에 서버를 켤 때 로그에 `감지: ABPS…`와 잠김 표시가 나오는지 봐야 합니다.
- 빼고 싶으시면 `E:\SPT 4.1\SPT_Runtime\user\mods\Gravity` 폴더 하나만 지우면 됩니다.

**공개 푸시 — 아직 하지 않는 것을 권장합니다.**
- GitHub `danyhappy564-cmyk/Gravity`는 **공개 저장소**입니다. `main`이 아닌 갈래만 올려도 누구나 볼 수 있습니다.
- 1.0 전까지 피드백을 받지 않기로 하셨으므로, 백업이 필요하면 ① 저장소를 비공개로 바꾼 뒤 갈래를 올리거나 ② 지금처럼 로컬에만 두는 두 가지 중 하나입니다.
- 미추적 폴더 `branding/`(아이콘 시안)은 이 작업에서 건드리지 않았습니다.
