# Gravity 1.0.3 스폰 미리보기 조사·수정 검증

## 결론

미리보기 체크박스 때문이 아니라, 이벤트가 발동할 때만 사용하는 확률 100% 항목을 일반 등장으로 합산하는 오류를 재현했습니다. Gravity의 미리보기 집계·표시만 수정했습니다. ISB 호환 기능·설정·어댑터를 추가하지 않았으며 실제 레이드의 스폰·이벤트 처리도 변경하지 않았습니다.

## 제보와 분석 범위

- 실제 서버 웹 UI의 개발·확인 → 10번 굴리기에서 세관 블랙디비전 25%인데 매 판 표시되고, 사냥조가 꺼진 삼림에서도 표시된다는 제보입니다.
- ISBBossCommander도 매 판 표시되며, 제보자는 실제 레이드를 시험하지 않았습니다. 화면 표시만으로 실제 매 판 생성된다고 판단할 수 없습니다.
- 사용자 지시에 따라 ISB 지원은 작업 범위에서 제외했습니다. 공개 원본은 조건부 항목의 의미를 확인하는 참고 자료로만 조사했습니다.

## 원인과 근거

ISB 공개 4.1 브랜치의 조사 커밋은 `e108bd0083dd4528ecc6c2f4cd81907ba3ff47e9`입니다. [ISBSpawnController 원본](https://github.com/Sam-C-137/ISB-Special-Forces/blob/e108bd0083dd4528ecc6c2f4cd81907ba3ff47e9/Server/Controllers/ISBSpawnController.cs#L1853)의 AddISBSecretSpawns는 해당 맵의 enableSecrets가 켜지면 다음 항목을 등록합니다.

| 항목 | 항목 확률 | 발동 조건 | 원본 위치 |
|---|---:|---|---|
| ISBBossCommander / bd_clash_hunt | 100% | botEvent | 1886~1907행 |
| blackDivAssault / bd_counterattack | 100% | botEvent | 1910~1938행 |
| ISBBossCommander / massacre_hunt | 100% | botEvent | 1943~1969행 |

이 100%는 이벤트 조건이 충족된 경우의 항목 확률입니다. 매 레이드 무조건 등장한다는 뜻은 아닙니다. 제보자 설치본의 버전 및 실제 이벤트 발동 여부는 확인하지 못했습니다.

Gravity의 GravityRuntime.Roll(미리보기 결과 집계)은 TriggerName을 확인하지 않고 BossChance만 굴렸습니다. 따라서 일반 사냥조가 25%로 정상 계산되거나 삼림에서 제거되어도, 남아 있는 조건부 100% 항목 때문에 블랙디비전이 항상 등장한 것처럼 보였습니다. 기존 결과 이름도 블랙디비전과 웨지를 하나로 표시했습니다.

실제 서버의 미리보기 버튼은 저장된 서버 설정과 맵 데이터 복제본으로 계산합니다. 버튼 클릭 시 화면의 미저장 설정이나 별도 블랙디비전 체크값을 전달하지 않습니다. 설정을 바꿨다면 먼저 저장해야 합니다.

## 수정 내용

1. 이벤트·퀘스트·상호작용 등 이름 있는 발동 조건은 일반 등장에 합산하지 않고 '조건부 이벤트 후보' 열로 구분합니다. 이벤트 발동 자체는 계산하지 않습니다.
2. 발동 조건이 없거나 none이면 기존대로 일반 확률을 굴립니다. 사냥조의 TriggerId=hunt만으로 조건부로 분류하지 않습니다. 0% 조건부 항목은 후보에서도 제외합니다.
3. 블랙디비전과 웨지의 결과 이름을 구분하고, 서버 저장값 사용 및 미리보기의 한계를 한영 화면·README에 명시했습니다.
4. 구형 서버 응답처럼 조건부 필드가 없어도 웹 화면을 표시할 수 있습니다.

모드별 특별 처리나 ISB 이름에 따른 생산 코드 분기는 없습니다. 다른 모드가 등록한 이벤트 항목을 삭제하거나 실제 발동을 막는 수정도 없습니다.

## 재현과 검사

ISB 원본에서 확인한 형태의 조건부 항목을 맵 데이터에 넣고 Gravity의 실제 미리보기 계산 함수를 실행했습니다. 설치된 ISB와의 통합 시험은 아닙니다.

| 조건 | 수정 전 일반 등장 표시 | 수정 후 일반 등장 표시 |
|---|---:|---:|
| 세관 사냥조 25% + 조건부 100% 항목 | 블랙디비전 500/500 | 블랙디비전 134/500 (26.8%) |
| 삼림 사냥조 꺼짐 + 조건부 100% 항목 | 블랙디비전 10/10 | 블랙디비전 0/10 |

수정 후 두 조건 모두 이벤트 항목은 후보로 별도 표시했습니다. 500회 결과는 고정 시드의 재현 수치이며 모든 실행에서 정확히 25%가 된다는 보장은 아닙니다. 미리보기의 10회만으로 확률 적용의 정확성을 판단해서도 안 됩니다.

- 수정 전 서버 회귀 검사 2개·웹 표시 검사 2개 실패를 확인했습니다.
- 수정 후 .NET 전체 480개·웹 전체 70개 통과, 건너뜀·실패 0개입니다.
- Release 빌드는 경고 0개·오류 0개입니다.
- 일반 사냥조, 이름 있는 발동 조건, none의 대소문자·공백, 0% 조건부, 블랙디비전/웨지 이름, 구형 응답을 검사했습니다.

## 배포와 미검증

사용자는 기존 공개 1.0.3에 수정본을 교체하고 로컬 게임 파일도 업데이트하도록 승인했습니다. 이전 ZIP·릴리즈 노트와 설치 파일은 백업하며, 공개 ZIP 재다운로드 해시 및 설치 파일 해시의 최종 결과는 배포 검증 자료에 기록합니다. 버전 번호는 1.0.3으로 유지합니다.

이번 미리보기 수정의 실제 게임 실행·제보자 동일 모드 구성·ISB 이벤트 발동은 미검증입니다. 앞선 시작 스폰 수정의 공장·인터체인지 인게임 검증과 이번 미리보기 자동 검증을 구별합니다. ISB 호환 지원을 약속하거나 실제 매 판 스폰 문제를 해결했다고 주장하지 않습니다.
