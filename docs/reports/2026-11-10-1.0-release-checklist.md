## A. 인게임 검증 (SlopBridge, 무적, 끝나면 원복)

1. **공장 1판** — PMC 시작 스폰·스캐브 보충·근처 보충. FactoryClassic 변형 맵 무한 로딩 주의.
2. **13맵 짧은 판**(맵마다 5~8분) — 맵별 PMC·스캐브·보스·특수 봇 수(roles 로그), 서버 오류, 게임 errors.log. Manimal 맵 변형 주의.
3. **상한 판단** — 세관처럼 맵 상한(옛 저장값)이 PMC·보스·팩션으로 차서 스캐브가 0이 되는 경우: 기본 상한·맵값 이어받기 규칙이 맞는지 결정(사용자).
4. **장비 실제 생성** — (a) 원작 프리셋 적용 판: 모드 무기 0, 판 등급·판 확률, 탄 목록 (b) Gravity 자동 판: 새 탄약·의약품 가격 티어(티어 위 제외) 반영. 봇 20명 이상 인벤토리 확인.
   (c) **부착물 티어**: T1·T7 봇 무기를 비교해 낮은 티어 봇이 비싼 부착물을 덜 다는지, 그러면서도 조준경·개머리판 등이 빠진 '맨 총'이 없는지, 총이 깨져 생성 실패(서버 로그 Nullable 예외)가 없는지. 무기 구성 '부착물에도 티어 적용'을 끈 판도 1회.
5. **이벤트** — 웹에서 켠 이벤트가 레이드에 반영되는지 1회.
6. **SVM 레이드 시간** — 실제 레이드 타이머가 웹 계획 시간과 같은지.
7. **특수 봇 시간** — 저격 스캐브·로그의 실제 등장 시각이 타임라인 설정과 같은지, 0명 설정 시 안 나오는지.
8. **스폰 구역 끔** — 한 종류 전부 끔(전부 켬으로 처리)·일부 끔 동작.
