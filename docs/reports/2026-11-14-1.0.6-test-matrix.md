# Gravity 1.0.6 시험 범위 (1.0.5 → 1.0.6 전체)

v1.0.5 태그 이후 바뀐 **모든 기능**을 시험 항목으로 풀어 둔 표다. 로컬 계획 `docs/superpowers/plans/2026-11-14-1.0.6-local.md` 3단계가 이 표를 따른다.
코드 근거는 `git log v1.0.5..HEAD`(기능 커밋 21개), 커밋별 설명은 검증 보고서 `2026-11-14-1.0.6-validation.md`.

- **우선순위**: 필수 = 릴리즈 전 반드시 / 권장 = 시간이 되면 이번에 / 선택 = 미검증 항목 확인용(실패해도 릴리즈는 가능, 노트에 "알려진 점"으로).
- **방법**: 판 = 실제 레이드(SlopBridge로 시작·무적·읽기) / 로그 = 서버 로그·`BepInEx\LogOutput.log`·`config\reports\` / 웹 = 실제 서버의 웹 화면(크롬) / 시험 = 자동 시험(.NET·웹).
- **증거**: 항목 ID 이름으로 `F:\코딩\Index\클로드방\gravity106-check-<날짜>-v001\<ID>\`에 로그 줄·스크린샷·jsonl. 결과는 이 문서 맨 아래 "결과" 표에 적는다.
- 판마다 진단 로그 **자세히**, 봇 장비 기록 **켬**(체력·티어 항목), 시작 보호·무적으로 판이 끊기지 않게.
